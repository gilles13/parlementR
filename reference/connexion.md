# Ouvrir ou reutiliser la connexion DuckDB

Ouvrir ou reutiliser la connexion DuckDB

## Usage

``` r
connexion(chemin = NULL, creer = FALSE)
```

## Arguments

- chemin:

  Chemin de la base ; NULL utilise la base par defaut.

- creer:

  Creer la base si elle est absente (reserve a l'initialisation).

## Value

Une connexion DuckDB valide.
