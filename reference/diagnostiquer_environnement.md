# Diagnostiquer les capacites de l'environnement local

Controle la disponibilite des logiciels et bibliotheques utiles aux
rapports, sans installation ni acces reseau.

## Usage

``` r
diagnostiquer_environnement(tester = TRUE)
```

## Arguments

- tester:

  Executer les tests locaux HTML, PDF et ecriture (TRUE par defaut).

## Value

Objet de classe \`diagnostic_parlementR\` contenant les capacites,
bibliotheques, logiciels, tests et strategie de sortie.
