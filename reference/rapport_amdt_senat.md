# Rapport sur les amendements du Senat

Rapport sur les amendements du Senat

## Usage

``` r
rapport_amdt_senat(
  references,
  fichier = NULL,
  ouvrir = FALSE,
  surligner = TRUE,
  pdf = TRUE
)
```

## Arguments

- references:

  Resultat de rech_amdt_senat().

- fichier:

  Fichier PDF de sortie.

- ouvrir:

  Ouvrir le PDF apres creation.

- surligner:

  Surligner le sujet recherche.

- pdf:

  Si FALSE, retourner les donnees structurees.

## Value

Chemin PDF ou donnees de recherche.
