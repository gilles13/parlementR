# Telecharger et lire un compte rendu de commission

Telecharger et lire un compte rendu de commission

## Usage

``` r
lire_compte_rendu_an(ref, reunion = NULL)
```

## Arguments

- ref:

  Reference CRCANR ou URL HTML issue de url_compte_rendu_an().

- reunion:

  Ligne facultative de chercher_commissions_an().

## Value

Liste structuree (reference, URL, metadata, HTML et texte).
