# Construire le catalogue des actes gouvernementaux

Construire le catalogue des actes gouvernementaux

## Usage

``` r
construire_catalogue_gvt(db = NULL, depuis = 1959L)
```

## Arguments

- db:

  Connexion DuckDB facultative.

- depuis:

  Premiere annee retenue.

## Value

Tibble des actes distincts, avec leur provenance.
