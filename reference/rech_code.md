# Rechercher les noms simplifies des codes LEGI installes

Rechercher les noms simplifies des codes LEGI installes

## Usage

``` r
rech_code(recherche = NULL, db = NULL)
```

## Arguments

- recherche:

  Texte facultatif recherche dans le nom complet ou simplifie.

- db:

  Connexion DuckDB facultative.

## Value

Tibble de deux colonnes : nom_complet et nom_simplifie.
