# Rapport documentaire multisource

Rapport documentaire multisource

## Usage

``` r
rapport_docs(
  references,
  fichier = NULL,
  ouvrir = FALSE,
  surligner = TRUE,
  pdf = TRUE
)
```

## Arguments

- references:

  Resultat de rech_docs().

- fichier:

  Fichier PDF de sortie.

- ouvrir:

  Ouvrir le PDF apres creation.

- surligner:

  Surligner le sujet recherche.

- pdf:

  Si FALSE, retourner les donnees structurees.

## Value

Chemin PDF ou tableau de documents.
