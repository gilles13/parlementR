# Hemicycle des deputes par groupe

Hemicycle des deputes par groupe

## Usage

``` r
graphique_hemicycle(donnees, titre = "Assemblée nationale", rangees = 10L)
```

## Arguments

- donnees:

  Tableau avec les colonnes groupe (sigle) et n (effectif).

- titre:

  Titre du graphique.

- rangees:

  Nombre de rangees de sieges.

## Value

Un objet ggplot.
