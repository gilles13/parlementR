# Frise des presidences et chefs de gouvernement

Frise des presidences et chefs de gouvernement

## Usage

``` r
bonus_gouvernement(
  mandats,
  depuis = as.Date("1946-01-01"),
  jusqua = Sys.Date()
)
```

## Arguments

- mandats:

  Table des mandats Wikidata deja disponible localement.

- depuis, jusqua:

  Dates de debut et de fin.
