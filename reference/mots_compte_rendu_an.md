# Frequences lexicales d'un compte rendu de commission

Frequences lexicales d'un compte rendu de commission

## Usage

``` r
mots_compte_rendu_an(cr, exclusions = character())
```

## Arguments

- cr:

  Objet issu de lire_compte_rendu_an().

- exclusions:

  Mots supplementaires a exclure.

## Value

Tibble mot, n.
