parlementR · Cheatsheet

Explorer les données parlementaires françaises avec R

Actualiser

Démarrer

Ouvrir la base locale.

library(parlementR)
db = connexion()

Mettre à jour

Actualiser les jeux disponibles.

actualiser(db = db)

Importer les dossiers

Charger une archive officielle.

importer_dosleg(db = db, archive = archive)

Importer les questions

Charger les questions du Sénat.

importer_questions(archive = archive, db = db)

Importer Dole

Alimenter les données locales.

importer_dole(db = db)

Fermer la base

Libérer la connexion locale.

fermer_base()

Explorer

Parlementaires

Consulter députés et sénateurs.

fiche_deputes(db = db)
fiche_senateur(nom = "Dupont", db = db)

Dossiers législatifs

Rechercher des textes parlementaires.

rechercher_dossiers("logement", db = db)

Thèmes du Sénat

Lister les thèmes officiels.

lister_themes(db = db)

Questions écrites

Rechercher puis consulter une question.

q = rechercher_questions("logement", db = db)
consulter_question(q$id[[1]], db = db)

Explorer dans Shiny

Afficher un tableau interactif.

shiny_senat_question(db = db)

Produire

Fiche de sénateur

Créer une fiche PDF individuelle.

produire_fiche_senateur("Dupont", db = db)

Dossier législatif

Créer le PDF d’un dossier identifié.

produire_dossier(uid = uid, db = db)

Rapport législatif

Produire un rapport thématique.

rapport_legislatif(db = db, sujet = "logement")

Question du Sénat

Créer le PDF d’une question.

produire_question(id = id, db = db)

Ensemble de questions

Créer un PDF par sujet.

produire_questions("logement", db = db)

Synthèse thématique

Produire un document sur un sujet.

produire_sujets("logement", db = db)
