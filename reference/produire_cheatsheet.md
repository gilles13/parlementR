# Produire la cheatsheet PDF de parlementR

Genere une fiche A4 paysage, en trois colonnes, selon le modele de la
cheatsheet assembleer. Necessite Chromium.

## Usage

``` r
produire_cheatsheet(sortie = "/tmp/parlementR-cheatsheet.pdf", ouvrir = TRUE)
```

## Arguments

- sortie:

  Chemin du PDF produit.

- ouvrir:

  Ouvrir le PDF apres generation.

## Value

Chemin du PDF, invisiblement.
